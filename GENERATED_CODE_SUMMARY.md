### 4. **Narrative Generation LLM Prompt** (`src/forecaster/llm/prompts/narrative_generation.yaml`)

YAML-versioned prompt that converts forecast data into a narrative.

**Inputs:**
- Forecast EPS, consensus, confidence
- Lens outputs (name, impact, finding)
- Model diagnostics (MAE, comparables range)
- Regime description

**Output (JSON schema):**
```json
{
  "title": "string",
  "thesis": "string (one sentence)",
  "our_forecast": "string",
  "consensus_context": "string",
  "our_case": {
    "reason_1": {"evidence": "...", "quote": "...", "impact": "..."},
    "reason_2": {...},
    "reason_3": {...}
  },
  "risks": ["risk A", "risk B", "risk C"],
  "narrative": "400–500 word prose"
}
```

**Why YAML?** Versioned in git, easy to iterate on without touching Python code.

---

### 5. **Narrative Generation Stage** (`src/forecaster/pipeline/narrative.py`)

Python orchestrator that:
1. Loads the prompt template
2. Extracts forecast data from `forecast.json`
3. Calls Claude/GPT-4 with structured response schema
4. Validates output (word count, schema compliance)
5. Writes to `out/forecast.json` under `narrative` key

**How to integrate:** Add to pipeline orchestration (likely in `cli.py` after judge stage)

**Cost:** ~0.05 calls, ~$0.10 per run (low priority cost-wise)

- Fallback: hand-write a 3-sentence summary and put it in the one-pager

- Yes! Visit `http://localhost:3000/narrative`, hit Ctrl+P, save as PDF or print
