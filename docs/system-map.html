forecasting

Consensus is not a forecast. It is analysts' good analysis with a thumb on the scale — estimates walked down 3–4% during the quarter, 58–63% of guiding companies guiding negative, then 78% beating the bar they set. That is incentive, not error. So: reproduce the analysis, strip the incentives, then ask the one question no individual analyst can — where is consensus structurally weak? forecast = consensus + λ · (own − consensus)

01 The pipeline

Twelve stages, A through I with three verification layers beside the chain rather than in it. Every stage emits events, so the live view is driven by running the pipeline rather than by a separate animation — and replay is free, because the UI reads a recorded event log through the identical code path.

03 The invariants

Breaking any of these is a bug, not a tradeoff.

point-in-time

Every source method takes as_of and must not return anything filed after it — including restatements of historical periods. Never swallowed: a leak raises rather than quietly flattering the backtest.

no number without provenance

A Claim cannot be constructed without a source and a non-empty verbatim quote. V1 string-matches every quote against its document. A lens citing evidence that does not exist is dropped.

lenses are blind

No parameter through which one lens's output reaches another. Diversity is the whole point of an ensemble, and their disagreement is an input to λ that means nothing if they saw each other's work.

materiality, never votes

No averaging, plurality or majority logic anywhere in aggregation. Six lenses agreeing on a weak signal lose to one carrying the company's own guidance with a quote.

robust statistics only

Medians and MAD; winsorize before any mean. Never calibrate on a cap-weighted aggregate — one recent headline surprise went +39.3% → +12.6% on excluding a single company.

the model must tie

Assets = liabilities + equity in every projected year, with cash coming off the cash flow statement rather than plugging the gap. A model that balances while being wrong is worse than one that does not balance.

05 What is not done

Listed as prominently as what is. A status board that only shows green teaches nothing.

λ is still asserted, not fitted. FITTED_BETA holds three placeholder numbers where the Block-1 regression output should be. FITTED_BETA_MEASURED = False.

What changed: the baseline it has to beat now exists — MAE 0.1868 on 487 cases. What has not: fitting β needs an own estimate per case, which is the judge's output, which is a pipeline run per case. At $1.07 a run that is roughly $520 for the full set. The regression and the per-regime table are written and tested; what is missing is the spend, not the code.
open
  • Lens abstention. On the last cold run 4 of 8 lenses came back with an empty citation list and were dropped after the work was done and billed. The constraint now lives in the decoding schema rather than in a post-hoc check, but the rate has not been re-measured across enough runs to call it fixed.
  • FX leg is inert. The geographic split gives the exposure, but regions are not currencies — without a mapping the adjustment degrades to zero rather than to a guess.
  • Segment coverage is 10 of 12. Exxon and UnitedHealth decline safely — no subset of their members reconciles — which is the designed outcome, not a silent failure.

What one live run cost, and what it was worth. $3.10 across three runs, and every one of these was invisible to the test suite because nothing raised — the pipeline finished, produced a number, and was quietly worse.
The import that was never there industry was unimported in the acquirer and a local variable of the same name masked it. Every cold run died. It survived because every recent run was a replay — and replay is the one path that never executes acquisition.
The cache, twice The corpus sat behind the per-lens instructions, and caching is a prefix match. Fixed — and the next run still showed cached_in=0, because the fan-out was simultaneous and an entry only exists once a write has returned. Now: written once at 14,206 tokens, read seven times.
The judge, twice A free-form quantiles dict came back empty on two consecutive runs, with the numbers written into the prose instead — so the single most expensive call was discarded for a degraded fallback. Five named floats fixed it.
The lens that cannot hallucinate Mechanical was dropped for eight fabricated citations. It has no model in it. The claims were pointers from the submissions index, string-matched against the document they point at — the check was comparing the wrong two things.
Deliberately out of scope: primary research. Nine items on the analyst's workflow need a human in a room — management meetings, expert networks, channel checks, customer calls. Approximating them produces a system that is a worse analyst, not a differently-abled one. The compensating edge is the opposite of theirs: forty quarters read in ninety seconds with the identical test applied to every one, across twelve peers simultaneously. That is not a substitute for being in the room. It is a different instrument.
