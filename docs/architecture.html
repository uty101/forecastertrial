The lenses are blind to each other Diversity is the point. Let them see each other's work and they converge — and converging is how you rebuild consensus, which scores zero.
Reconcile before challenge A lens that can't make its own arithmetic add up, or that cites a quote not in the source, is dropped and logged — never silently averaged in.
The advocate is a column, not a step Each case argued properly and then argued against, before anything is compared. This is what took Alistair's own system from 0 to 92%.
λ sits outside the forecast path Everything left of it produces an estimate. λ decides how much to trust it against sixty-one analysts. That separation is the thesis.
